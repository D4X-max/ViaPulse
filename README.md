# Overview

ViaPulse is an intelligent civic issue reporting platform that transforms the way citizens and municipal authorities collaborate to maintain public infrastructure.

Citizens can report issues such as potholes, damaged streetlights, garbage accumulation, water leakages, broken roads, and other public hazards using images, location, and natural language.

Powered by **Google Gemini 2.5 Flash**, ViaPulse automatically analyzes submitted reports, categorizes issues, estimates severity, detects duplicate complaints, asks intelligent follow-up questions when additional information is needed, translates multilingual reports, predicts future infrastructure risks, and assists municipal authorities in prioritizing actions.

Instead of acting as a traditional complaint portal, ViaPulse functions as an **AI Civic Copilot** that improves the quality of reports before they ever reach the authorities.

---

# Our Solution

ViaPulse leverages **Artificial Intelligence**, **Geospatial Intelligence**, and **Community Participation** to build an autonomous civic issue management platform.

Instead of relying on manual processing, ViaPulse automatically:

- Understands uploaded images
- Categorizes infrastructure issues
- Predicts severity
- Generates structured municipal reports
- Detects duplicate complaints
- Requests clarification when confidence is low
- Predicts future infrastructure hotspots
- Tracks issue resolution
- Keeps citizens informed throughout the lifecycle

The result is faster reporting, improved municipal efficiency, and greater transparency between citizens and authorities.

Instead of blindly accepting incomplete reports, Gemini evaluates its confidence.

- Is the pothole blocking traffic?
- Approximately how large is it?
- Has this issue existed for more than a week?
- Can you upload a clearer image?

This significantly improves report quality and reduces manual verification.

# 🚀 Getting Started

## 📋 Prerequisites

Before running ViaPulse, ensure you have the following installed:

- Node.js (v18 or above)
- npm or yarn
- Git
- A Google AI Studio API Key
- A Firebase Project
- Google Maps Platform API Key

---

#  Installation

Clone the repository:

```bash
git clone https://github.com/yo/viapulse.git](https://github.com/D4X-max/ViaPulse.git
```

Navigate into the project:

```bash
cd ViaPulse
```

Install dependencies:

```bash
npm install
```

---

# 🔑 Environment Variables

Create a `.env` file in the project root.

```env
# Gemini
GEMINI_API_KEY=YOUR_GEMINI_API_KEY

# Firebase
VITE_FIREBASE_API_KEY=
VITE_FIREBASE_AUTH_DOMAIN=
VITE_FIREBASE_PROJECT_ID=
VITE_FIREBASE_STORAGE_BUCKET=
VITE_FIREBASE_MESSAGING_SENDER_ID=
VITE_FIREBASE_APP_ID=

# Google Maps
VITE_GOOGLE_MAPS_API_KEY=
```

---

# Running the Project

Start the frontend:

```bash
npm run dev
```

Start the backend:

```bash
npm run server
```

Or run both together (if configured):

```bash
npm run dev:full
```

The application will be available at:

```
http://localhost:5173
```
